# Backrooms Ultimate Edition mod


## Overview

Minecraft Forge mod for 1.12.2 thats adds the backrooms levels - all available to explore. All levels and entities are made by using information from wikidot.com

Mod is avaialble at [CurseForge](https://www.curseforge.com/minecraft/mc-mods/the-backrooms-ultimate-edition)

This repository also serves as the main page of issues for Backrooms Ultimate Edition mod. Currently only for version 0.1.7.
All bugs submitted here will be fixed in the next version of the mod.
Please make sure before submitting a bug that it still exist in the latest version of the mod and that it isn't in the closed section.

## Branch Overview

Minecraft Forge mod for 1.16.5 that adds the backrooms levels - all available to explore. All levels and entities are made by using information from wikidot.com

This branch does not have any levels and entities. As a matter of fact the 1.16.5 version was the first for which the mod development was started. Mod was then moved to Minecraft 1.12.2 because it was way easier to work with custom Dimensions than in Minecraft 1.16.5
